# Smile Lifting

Anti-aging face yoga game (English build).

## Run / Deploy
Open `index.html` in a browser — everything (art, music, code) is inlined in that one file.
Deploy it to GitHub Pages and the camera mirror + background music work too.

## Flow
Splash → Countdown (3·2·1·GO!) → Exercise (LIFT 2s / HOLD 15s / RELAX 3s × 3 steps, ~1 min) → Mission Clear

## Contents
- `index.html` — standalone game, ready to deploy
- `assets/` — source images and bgm.mp3
- `source/` — editable source (`Smile Lifting.dc.html` + `support.js` runtime)
